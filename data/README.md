# Dataset provenance

Dataset: Heart Disease (processed Cleveland subset)  
Publisher: UCI Machine Learning Repository  
Dataset page: https://archive.ics.uci.edu/dataset/45/heart+disease  
Archive URL used by the downloader: https://archive.ics.uci.edu/static/public/45/heart+disease.zip

The processed Cleveland file has 13 input columns and one target column. Missing entries are represented by `?`. The original target uses values 0–4; this project maps 0 to `0` (no disease) and values 1–4 to `1` (presence). The download script writes the normalized data locally. Review the source terms and cite UCI in the report.
